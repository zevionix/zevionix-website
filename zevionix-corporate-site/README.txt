# Zevionix Corporate Website

## Files
- `index.html` — Home
- `about.html` — About Zevionix
- `service.html` — Services
- `technology.html` — Technology
- `aura.html` — AURA project
- `team.html` — Leadership
- `contact.html` — Contact
- `css/style.css` — Shared responsive design
- `js/script.js` — Mobile navigation and footer year

## GitHub repository
Upload the contents of this folder into your existing `website/` folder, replacing the matching HTML/CSS/JS files. Keep the `website/` folder name.

The site uses relative links, so all pages work together from the same directory.

## GitHub Pages
If Pages publishes from the repository root, the URL will include `/website/`.
To use the root URL, configure Pages to publish from the `website` folder if your repository settings offer that option, or move these files to the repository root.

## Note
The contact form uses `mailto:` and opens the visitor's email app; it does not store submissions on a server. AURA is described as in development, not as a fully deployed product.
