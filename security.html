AES-256-GCM Envelope Encryption

All stored persistence (PostgreSQL tables, Kafka log segments, Iceberg Parquet files) uses dual-tier envelope encryption. Unique Data Encryption Keys (DEKs) are generated per tenant and wrapped by master Key Encryption Keys (KEKs).

All ingress, egress, and internal mesh channels mandate TLS 1.3 with Perfect Forward Secrecy (PFS). Legacy TLS versions and insecure cipher suites are hard-rejected at kernel edge proxies.

Network & Protocol Security

Secure API Design & Streaming Security

How our high-throughput gRPC microservices and Apache Kafka streaming backbones enforce identity, encryption, and authorization across distributed nodes.

gRPC Mutual TLS & OAuth2/OIDC

Cryptographic Workload Identity (SPIFFE/SPIRE)

Internal microservice communication strictly rejects plain HTTP/1.1 and unauthenticated RPCs. Every pod receives an ephemeral X.509 cryptographic identity certificate renewed every 60 minutes via SPIFFE/SPIRE.

  • mTLS Peer Verification: Both client and server authenticate X.509 SANs before opening HTTP/2 stream multiplexing.
  • Token Exchange & Claims: JWT/OIDC claims decoded and validated via Envoy WASM filters in under 0.8ms.
  • Strict Protobuf Schemas: Enforced input validation preventing buffer overruns, SQL injections, and prototype pollution.
  • eBPF Kernel Egress Filter: Cilium network policies prevent pods from initiating unauthorized lateral network handshakes.
Enforced: TLS 1.3 · SPIFFE SVID · Protobuf Linters · Rate-Limiting Envoys

Hardened Kafka Streaming Security

SASL/SCRAM-SHA-512 & Client-Side Encryption

Our petabyte-scale event backbones handle telemetry without compromising data confidentiality. Even Kafka cluster infrastructure operators cannot view sensitive business payloads.

  • Client-Side Payload Encryption: Producers encrypt JSON/Avro byte payloads with tenant-specific AES-GCM keys prior to Kafka broker socket write.
  • Granular Topic ACLs: Principle of Least Privilege enforced per service group via SCRAM-SHA-512 credentials.
  • Encrypted Disk Segments: Broker storage volumes encrypted via dm-crypt/LUKS with dedicated AWS KMS keys.
  • Audit Log Streaming: All broker authorization decisions and ACL evaluations streamed to SIEM in real-time.
Enforced: SASL/SCRAM-512 · Client-Side Envelope · dm-crypt · Zero Plaintext Storage
